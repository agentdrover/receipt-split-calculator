# История изменений

Формат — по мотивам Keep a Changelog, версии — Semantic Versioning.
Раздел на каждый выпуск: дата и группы «Добавлено», «Изменено», «Исправлено».
Текст для GitHub Release лежит в `docs/releases/<тег>.md`; порядок выпуска —
в [docs/releasing.md](docs/releasing.md).

## [1.0.0] — 2026-11-17

Первый публичный выпуск.

### Добавлено

- Съёмка чека камерой и выбор фото из галереи; сжатие и поворот на устройстве.
- Распознавание позиций через провайдера: DeepSeek, OpenRouter или свой
  OpenAI-совместимый адрес с моделью, принимающей изображения.
- Глубокое распознавание: отдельный переключатель в настройках и кнопка
  «Распознать точнее» на экране проверки.
- Экран проверки: правка, добавление и удаление позиций, сверка с фото, зум.
- Выбор своей доли: «моё целиком», «общее на k человек», «не моё».
- Распределение скидки и обслуживания пропорционально своей части.
- Чаевые процентом или фиксированной суммой.
- Экран итога с разбивкой, копированием текста и системным «Поделиться».
- Локальная история чеков с удалением данных.
- Настройки провайдера: ключ, адрес, модель; ключ хранится на устройстве
  в защищённом хранилище и не попадает в резервные копии.
- Тёмная тема, жест «назад», иконка и логотип приложения.

### Изменено

- Версия приложения вынесена в `app/version.properties`; release-сборка
  подписывается ключом владельца и проверяется по отпечатку сертификата.

### Известные ограничения

- Интерфейс и тексты только на русском; строки не вынесены в ресурсы.
- R8 выключен: release APK больше, чем мог бы быть.
- Публикация в Google Play отложена; установка — из GitHub Release.
- Первый выпуск с релизным ключом ставится только после удаления
  debug-подписанной беты, локальная история при этом теряется.
